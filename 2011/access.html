「第22回光物性研究会」会場へのアクセスについて

会場(熊本大学・工学部百周年記念館)は、熊本大学黒髪キャンパスの南地区にあるガラス張りの建物です。 会場へのアクセスに際し以下の情報をご参照ください。
  • 熊本大学の交通アクセス紹介ページ

  • Google map

  • JR熊本駅から市内へのアクセス。

    • 市電が路線も単純で、150円均一料金です。

      熊本駅前→(熊本市交通局:市電)→辛島町→・・→通町筋 →水道町→・・健軍方面

      時刻表等は下の情報をご参照ください。

    • 市内バスも利用できます。

  • 阿蘇熊本空港から市内へのアクセス。

    阿蘇熊本空港→(空港リムジンバス)→通町筋→交通センター→・・・→熊本駅前
    時刻表等は下の情報をご参照ください。

  • 阿蘇熊本空港から大学へ直接アクセスするには、次の方法があります。

    • 阿蘇熊本空港→(空港リムジンバス)→通町筋(乗換)→(バス)→大学前
      時刻表等は下の情報をご参照ください。

    • 阿蘇熊本空港→(空港ライナー)→JR肥後大津→(JR豊肥本線)→JR竜田口大学前→(市内方面バス)→大学前

      研究会開催期間は、阿蘇熊本空港→JR肥後大津間の空港ライナーが無料で利用できます。
      以下の関連Webページをご参照ください。

      • 空港ライナー(阿蘇くまもと空港と肥後大津駅との往復直行便)
      • JR九州、 JR肥後大津駅、 JR竜田口駅
      • 「竜田口駅前」バス停( 九州産交バス,  熊本電鉄バス )
      • 「大津駅前」バス停( 九州産交バス )

  • ホテルの多くは「交通センター」、「通町筋」、「水道町」等のバス停の近くにあります。 これらのバス停から熊本大学へのアクセスには、バスの経路表示で「熊本大学前」と記載のあるバスにご乗車ください。

  • バスで「熊本大学前」までたどり着けなくても、経路表示の省略表記で「子XX」とあるバスは、大学近くの 「子飼橋」バス停を必ず通ります。「子飼橋」バス停から大学までは徒歩10〜15分です。「熊本大学前」 まで行くバスの本数は多くはないので、「子飼橋」で降車して歩くのも便利です。

  • 市内の全てのバスと市電共通で利用できる1割の割引つきのプリペイドカード「TO熊(つーゆー)カード」が、 降車時の混乱を解消できますし、便利です。
    グループで乗車される場合は、降車直前に運転手に「大人何人」と言えば、1枚のカードで支払えます。
    カードの残額が足りない場合は不足分を現金で払ってカードを使い切ることももちろん可能です。
    空港・市内間のリムジンバスでも使えます。
    交通センターの自販機で販売もされていますし、バス・市電の社内でも販売しています。
    「TO熊(つーゆー)カード」については 交通センターの紹介ページや、 九州産交の紹介ページをご参照ください。

  • 市内バスと市電の経路等の情報は次のとおりです。
    • 九州産交バス
    • 熊本電鉄バス
    • 熊本都市バス
    • 熊本市交通局(市電)
